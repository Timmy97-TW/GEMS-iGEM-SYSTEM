# GEMS iGEM System

The 2027 operating system for the GEMS Taiwan iGEM team, drawn from the 2026 season: what broke this year, the system rules and hard gates, the ID system and Hub tabs, the Google Drive structure, the year of documents, who stewards what, the Student Advisor programme, and the timeline planned backwards from the iGEM deadlines.

一個網頁，看懂 2027 年的團隊系統：今年哪裡壞了、系統規則與硬關卡、ID 與 Hub 分頁、Google Drive 結構、文件年表、誰負責什麼、Student Advisor 計畫、從截止日往回排的時程。

## Files

- `index.html`: page skeleton
- `assets/data.js`: all content, Chinese and English side by side. Edit this file to change any text, role, count or date.
- `assets/app.js`: rendering and interaction
- `assets/style.css`: styles

No build step and no external requests. Open `index.html`, or serve the folder:

```bash
python3 -m http.server 8765
```

Everything here is a proposal (system spec v0.2). Dates follow the PI's 2027 schedule; iGEM dates marked `?` are estimates until 2027 is announced. Wiki Freeze shows as `10/6–13?` and internal gates back-plan from 10/6.

This repo is public. It summarises the system only: no real names, contact details, fees, individual records, Drive links, research strategy or project content.
