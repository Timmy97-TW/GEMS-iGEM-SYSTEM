# GEMS iGEM System

The 2027 operating system for the GEMS Taiwan iGEM team, drawn from the 2026 season: what broke this year, the six asset streams and their registers, the Google Drive structure, who stewards what, and the timeline planned backwards from the iGEM deadlines.

一個網頁，看懂 2027 年的團隊系統：今年哪裡壞了、六條素材流與登錄表、Google Drive 結構、誰負責什麼、從截止日往回排的時程。

## Files

- `index.html`: page skeleton
- `assets/data.js`: all content, Chinese and English side by side. Edit this file to change any text, role, count or date.
- `assets/app.js`: rendering and interaction
- `assets/style.css`: styles

No build step and no external requests. Open `index.html`, or serve the folder:

```bash
python3 -m http.server 8765
```

Deadlines follow the 2026 iGEM calendar until the 2027 dates are announced.
